# Добавление шрифта

Шрифты хранятся файлами на нашем сервере (self-host), а не подключаются с внешнего CDN. Иначе в печатном PDF шрифт может не загрузиться, и печать отличится от превью. Сначала прочитай раздел «Текст и шрифты» в CLAUDE.md. Конфиг шрифтов — `frontend/src/book/fonts.json`, файлы — `frontend/public/fonts/`, лицензии — `frontend/public/fonts/licenses/<id>-OFL.txt`, скрипт подготовки — `tools/fonts/process_fonts.py`.

## Шаги
1. **Выбери шрифт** (обычно Google Fonts, исходники — https://github.com/google/fonts, папка `ofl/<имя>/`). Проверь лицензию: должна разрешать использование в коммерческом продукте и самостоятельный хостинг (у большинства Google Fonts это OFL). Если лицензия неясна, скажи пользователю и не добавляй.
   **Reserved Font Name.** Посмотри начало `OFL.txt`: если там есть «with Reserved Font Name», файл нельзя изменять (урезать набор символов, вырезать начертания из переменного шрифта) под тем же именем. Такой шрифт кладём исходным `.ttf` без изменений (в конфиге `modified: false`).
2. **Проверь кириллицу.** Шрифт должен содержать русские буквы А–Я, а–я, Ё, ё и знаки препинания. Проверь по самому файлу, а не по описанию на сайте (например, через `fontTools`: `python3 -c "from fontTools.ttLib import TTFont; ..."` и сравнение с набором кодов U+0410–U+044F, U+0401, U+0451). Если шрифт без кириллицы, не добавляй.
3. **Казахские буквы** (ә, ғ, қ, ң, ө, ұ, ү, һ, і) пока не обязательны, но проверь и отметь в конфиге поле `kk: true/false`, чтобы потом знать, какие шрифты подойдут для казахского.
4. **Конвертируй в woff2** шрифты без Reserved Font Name (`fonttools` с `flavor=woff2`, нужен пакет `brotli`): добавь строку в `FONTS` в `tools/fonts/process_fonts.py` и запусти его. Нужны начертания, которые реально используются: обычное, жирное (и курсив, если он есть в конфиге). Вырезая начертание из переменного шрифта, обнови внутренние имена (`updateFontNames=True`, скрипт так и делает), иначе в PDF шрифт будет называться по начертанию по умолчанию, например «Montserrat Thin».
5. **Положи файлы** в папку шрифтов проекта (найди её по существующим шрифтам). Имена: `<id>-regular.woff2`, `<id>-bold.woff2`.
6. **Добавь запись в конфиг** `frontend/src/book/fonts.json` (скрипт пишет её сам): `id` (латиницей), `name` (как видит пользователь), `category` (`handwritten` / `serif` / `sans`), `files` (`file` + `weight`: `"400"`, `"700"` или диапазон `"400 900"` у переменного), `bold`, `kk`, `license`, `modified`. Код приложения менять не нужно; backend читает тот же файл и проверяет шрифты в шаблонах и книгах. Если это не так, значит, конфиг устроен неправильно: скажи об этом.
7. **Проверь превью в редакторе:** добавь текстовый блок, выбери новый шрифт, напиши русский текст («Съешь же ещё этих мягких французских булок») и убедись, что глифы на месте и нет подстановки запасного шрифта. Это автоматизировано: `make e2e` (файл `e2e/text.mjs`) для каждого шрифта из `fonts.json` спрашивает у Chromium, какими шрифтами нарисован текст, и сверяет отметку `kk` на казахских буквах.
8. **Проверь печатный PDF.** Если шаг рендера PDF уже реализован, собери тестовый PDF с этим шрифтом и убедись, что шрифт встроен в файл (например, `pdffonts файл.pdf` — в списке должен быть шрифт, а не его замена). Рендер должен ждать `document.fonts.ready`. Если рендер ещё не реализован, скажи об этом пользователю, не пропуская молча.

## Правила
- Не подключай шрифты через внешние ссылки (Google Fonts CDN и т.п.).
- Не добавляй больше шрифтов, чем просили: каждый лишний шрифт увеличивает загрузку на телефоне.
- Если шрифт нужно убрать, сначала проверь, не используется ли он в существующих шаблонах и книгах, и не удаляй, пока не убедишься.

## Что сказать пользователю в конце
Одной-двумя фразами: какой шрифт добавлен, лицензия, есть ли кириллица и казахские буквы, встроен ли он в тестовый PDF (или что проверка отложена).
