# PNG-стикеры «Отношения» — на подключение позже

19 растровых стикеров в `NewStickers/`. Сейчас в проект **не подключены**: стикеры в
редакторе и PDF пока только векторные SVG (`frontend/src/book/stickers.json`). Шаблон
«Ты и я» (`templates/you-and-me.json`) оформлен без них — нашими SVG (набор «Рамки и бумага»,
`love-lips`).

## Что нужно для подключения (отдельный шаг)
- Поддержка растровых стикеров: облегчённая копия для редактора (webp до 512 px) и оригинал
  для печатного PDF; в `stickers.json` — оба файла; backend принимает `.png`/`.webp`.
- Проверка разрешения: стикер в шаблоне не крупнее, чем позволяет 300 dpi (столбец ниже);
  в редакторе — предупреждение «маленький», как у фото.

## Проверка файлов (все с прозрачным фоном, RGBA)
