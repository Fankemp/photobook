# Шаблоны книг

Один файл = один шаблон. Чтобы добавить шаблон, положите сюда `.json` и пересоберите backend:
`docker compose up --build -d backend`. При старте сервер проверяет все шаблоны и не запустится,
если какой-то файл с ошибкой (текст ошибки — в `make logs`). Проверить без запуска: `make test`.

## Структура

```jsonc
{
  "schemaVersion": 1,            // версия формата страниц, сейчас 1
  "id": "anniversary-classic",   // латиница в нижнем регистре, цифры, дефисы; уникален
  "name": "Наша история",        // название в каталоге
  "occasion": "anniversary",     // повод: anniversary, love, birthday, travel, mom, wedding, baby, family, other
  "formatId": "square-200",      // id из таблицы formats
  "preview": "…",                // необязательно: картинка для каталога (пока не используется, показываем обложку)
  "cover": { /* страница */ },    // передняя обложка
  "pages": [ /* страницы */ ],    // внутренние страницы, ровно pages у формата (сейчас 16, число
                                  // фиксировано: клиент страницы не добавляет и не удаляет)
  "backCover": { /* страница */ } // задняя обложка; необязательно — без неё пустая с фоном обложки
}
```

Страница: `{"id": "p1", "background": "#ffffff", "backgroundImage": "stripes-wine", "elements": [...]}`.
`background` — цвет страницы (и вылета), `backgroundImage` — необязательный узор поверх цвета: id из
`frontend/src/book/backgrounds.json` (полоски, горошек, плитка, кружево; рисует
`tools/backgrounds/generate.py`), ложится на весь лист с вылетом. Id страниц уникальны в шаблоне,
id элементов — в пределах страницы.

Координаты элементов `x, y, w, h` — проценты от страницы по линии реза (0–100).
Фото, прижатое к краю (`x: 0` или `x + w: 100`), на печати уйдёт в вылет.
Текст держите не ближе 8% к краю: ближе — безопасная зона, текст могут срезать (повёрнутый
блок проверяется по его углам). Фото не должно наезжать на фото, текст — на текст (проверяется);
подпись поверх фото и стикеры поверх чего угодно — можно. Исключение: фото целиком внутри
другого фото — это «вставка» (снимок с каймой поверх большого фото), так можно. В книге клиент может передвинуть, растянуть и повернуть текст —
положение из шаблона только стартовое, сам шаблон не меняется.

| Тип | Поля |
|---|---|
| `photo_slot` | `assetId` (null в шаблоне), `crop: {zoom ≥ 1, offsetX, offsetY}`, `shape` (`heart` — рамка-сердце; нет поля — прямоугольник) |
| `text` | `text`, `font` (id шрифта), `size` (пункты на печати), `color` (`#rrggbb`), `align` (`left`/`center`/`right`), `bold`, `rotation` (градусы, −180…180; необязательно) |
| `sticker` | `stickerId` (id из `frontend/src/book/stickers.json`), `rotation` (градусы, −180…180) |

Блок стикера задайте с пропорциями рисунка (`aspect` в `stickers.json` — ширина / высота):
на квадратном формате `h = w / aspect`. Рисунок вписывается в блок без искажений,
так что небольшая неточность не страшна.

Оформление «под фото» — набор стикеров «Рамки и бумага» (`frames-*`: полароид, снимок с каймой,
фотополоска, записка, лист бумаги, скотч, кружевное сердце, игральная карта, конверт, открытка…).
Порядок элементов = порядок слоёв: сначала рамка, потом фото в её окне. Окна рамок описаны в
`FRAME_WINDOWS` генератора (`p.framed(...)` ставит рамку и фото сразу).

## Генератор

Шаблоны `mom-tender`, `wedding-elegant`, `baby-first-year`, `family-album`, `you-and-me` собраны скриптом
`tools/templates/generate.py` из общих раскладок страниц (одно фото, сетка из четырёх, фото
с подписью, «месяц» и т.д.). Новый шаблон удобно описать там же — стиль (фон, шрифты, цвета)
и список раскладок — и запустить `python3 tools/templates/generate.py`. Скрипт перезаписывает
только описанные в нём шаблоны; остальные файлы правятся руками.

Сверка с референсом: `node template-shots.mjs <id>` в контейнере Playwright (как `make e2e`)
снимает каждую страницу шаблона 1200×1200 в `e2e/shots/tpl-<id>/` — положить рядом с картинками
референса (`reference/`, не в git) и сравнить положение, размеры и цвета.

Повод (`occasion`) — это ещё и фильтр в каталоге (`/?occasion=mom`): кнопка повода появляется,
когда есть хотя бы один шаблон с ним. Подписи поводов — в `frontend/src/i18n/ru.ts` (`occasions`).
