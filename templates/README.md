# Шаблоны книг

Один файл = один шаблон. Чтобы добавить шаблон, положите сюда `.json` и пересоберите backend:
`docker compose up --build -d backend`. При старте сервер проверяет все шаблоны и не запустится,
если какой-то файл с ошибкой (текст ошибки — в `make logs`). Проверить без запуска: `make test`.

## Структура

```jsonc
{
  "schemaVersion": 1,            // версия формата страниц, сейчас 1
  "id": "anniversary-classic",   // латиница в нижнем регистре, цифры, дефисы; уникален
  "name": "Наша история",        // название в каталоге
  "occasion": "anniversary",     // повод: anniversary, birthday, travel, mom, wedding, baby, family, other
  "formatId": "square-200",      // id из таблицы formats
  "preview": "…",                // необязательно: картинка для каталога (пока не используется, показываем обложку)
  "cover": { /* страница */ },    // передняя обложка
  "pages": [ /* страницы */ ],    // внутренние страницы, ровно столько, сколько pages у формата (сейчас 20)
  "backCover": { /* страница */ } // задняя обложка; необязательно — без неё пустая с фоном обложки
}
```

Страница: `{"id": "p1", "background": "#ffffff", "elements": [...]}`. Id страниц уникальны в шаблоне,
id элементов — в пределах страницы.

Координаты элементов `x, y, w, h` — проценты от страницы по линии реза (0–100).
Фото, прижатое к краю (`x: 0` или `x + w: 100`), на печати уйдёт в вылет.
Текст держите не ближе 8% к краю: ближе — безопасная зона, текст могут срезать (повёрнутый
блок проверяется по его углам). В книге клиент может передвинуть, растянуть и повернуть текст —
положение из шаблона только стартовое, сам шаблон не меняется.

| Тип | Поля |
|---|---|
| `photo_slot` | `assetId` (null в шаблоне), `crop: {zoom ≥ 1, offsetX, offsetY}` |
| `text` | `text`, `font` (id шрифта), `size` (пункты на печати), `color` (`#rrggbb`), `align` (`left`/`center`/`right`), `bold`, `rotation` (градусы, −180…180; необязательно) |
| `sticker` | `stickerId` (id из `frontend/src/book/stickers.json`), `rotation` (градусы, −180…180) |

Блок стикера задайте с пропорциями рисунка (`aspect` в `stickers.json` — ширина / высота):
на квадратном формате `h = w / aspect`. Рисунок вписывается в блок без искажений,
так что небольшая неточность не страшна.
